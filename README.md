# Weibo Reader（Windows Web 版）

把微博互动数据（发出的评论、收到的评论、@记录、用户微博、某条博文下的评论）归档到本机，
之后可离线浏览、搜索、生成 HTML 报告，并按计划自动检查新内容。

> 本仓库为**源代码包**，不含任何账号凭据与个人数据。首次运行会自动生成演示数据，
> 无需登录即可完整体验全部界面。

## 环境要求

- Windows 10/11
- Node.js 18 或更高版本（<https://nodejs.org>，选 LTS）
- 无需 `npm install`：项目零第三方依赖，只用 Node 内置模块

## 启动

双击 `start.bat`，或命令行：

```
node server/server.js
```

启动后浏览器会自动打开 <http://127.0.0.1:7788>。
首次启动是**演示模式**（内置 3 个示例用户、2 条博文、166 条互动），可随意操作，不产生任何费用。

## 取真实数据

1. 点右上角「登录微博」，按提示在浏览器中确认设备码授权
2. 在「用户库」粘贴微博主页地址或 UID 添加对象
3. 在「取数」选择内容类型、条数上限，点开始

取数按接口实际返回条数计费（约 3 credits/条），本地查看、搜索、生成报告均为 0 credits。

## 目录说明

| 路径 | 说明 |
|---|---|
| `server/` | 服务端：HTTP 路由、微博网关客户端、取数引擎、存储、搜索、报告、订阅调度 |
| `web/` | 前端：原生 HTML/CSS/ES Module，无构建步骤 |
| `test/` | 测试（`node --test`），共 115 项 |
| `docs/` | 需求（PRD）、架构（ARCH）、接口事实（API-FACTS）、验收报告（QA-REPORT）、使用手册 PDF |
| `data/` | **运行时生成**，存放账号配置与归档数据；不随包分发，请勿对外分享 |

## 运行测试

```
node --test
```

## 说明

- 仅监听 `127.0.0.1`，不对局域网或公网开放
- token 只保存在本机 `data/config.json`，任何接口响应只回传末 4 位
- 订阅定时检查跟随进程运行，关闭窗口即停止
- 同一 `data/` 目录只允许一个实例写入（有文件锁保护）
